## 📘 New book: *Kargo in Action*

<a href="https://hubs.la/Q04t76Rc0">
  <img src="https://images.manning.com/264/352/resize/book/7/fa4195f-536c-46fc-b0fb-8bd79eb1dea7/Cochrane-MEAP-HI.png" alt="Kargo in Action book cover" width="180" align="right">
</a>

Most teams can deploy to Kubernetes. Far fewer can answer: *what version is in staging, how did it get there, and is it safe for production?*

**Kargo in Action** is about closing that promotion gap. I wrote it with **Jesse Suen** and **Kent Rancourt**, the creators of Kargo. It follows one company as it grows from a single-service pipeline into a platform for dozens of teams and services. You'll learn how to:

- 🚀 Run Kargo alongside Argo CD and do your first end-to-end promotion
- 🗺️ Design promotion pipelines across environments, release candidates, and hotfix paths
- 🤖 Automate low-risk promotions and gate production behind approvals and verification
- ↩️ Roll back cleanly when a release goes sideways
- 📋 Produce the audit trail your compliance reviewers actually want

It's available now through the **Manning Early Access Program (MEAP)**. Read chapters as they're written, and get the final book when it ships.
